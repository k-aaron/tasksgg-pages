TasksGG

Google Tasks를 위한 macOS 데스크톱 앱. 브라우저 탭 없이, 사이드바에 목록을 두고 바로 씁니다.

이 앱은

내 Google 계정으로 로그인

Google OAuth로 로그인해서 본인의 Google Tasks 목록을 그대로 불러옵니다.

목록 · 하위 작업 · 정렬

여러 목록을 사이드바에서 전환하고, 하위 작업과 드래그 정렬을 지원합니다.

라이트 / 다크 모드

시스템 설정에 맞춰, 또는 직접 전환해서 사용할 수 있습니다.

데이터 처리 원칙

  • 이 앱은 별도의 서버를 운영하지 않습니다 — 모든 요청은 사용자의 기기에서 Google 서버로 직접 전송됩니다.
  • 제3자 분석 도구, 광고, 트래커를 포함하지 않습니다.
  • 자세한 내용은 개인정보처리방침을 참고해주세요.
